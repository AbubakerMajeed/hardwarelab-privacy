# Hardware Lab – Privacy Policy

This repo hosts the privacy policy page for the **Hardware Lab** iOS app.

Live URL: `https://YOUR_USERNAME.github.io/hardwarelab-privacy`

## Setup

1. Go to this repo on GitHub
2. Settings → Pages → Source: **Deploy from branch** → branch: `main` → folder: `/ (root)`
3. Save — the URL goes live in ~60 seconds

## Update email

Edit `index.html` and replace `YOUR_EMAIL@example.com` with your real contact email.
